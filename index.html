From product link to shipping quote

Confirm the variant

Open the CAFANS listing and check whether SuperBuy is available under Buy Link. At the agent, confirm the seller, size, color and quantity before paying. Compare garment measurements with a piece you already own, using the same measurement method.

Review warehouse photos

If inspection photos are available, check the size label and color against your order. For shoes, compare both soles and check that the requested length measurement is visible. For clothing, check the print placement, seams and zipper. If you see a mismatch, check the return window before approving shipment.

Compare the total cost

Add the item price, domestic delivery, agent fees, international freight and any applicable import charges. Compare shipping quotes using the packed dimensions and weight. A bulky, light jacket can cost more to ship if the carrier bills by volumetric weight.

SuperBuy spreadsheet FAQ

Where do the product listings come from?

This independent guide features products listed on CAFANS. Each product name opens its CAFANS detail page.

What if SuperBuy is missing from Buy Link?

If CAFANS shows a source URL, copy it into SuperBuy and verify that it opens the correct item. Check with the agent if the link or item is unsupported.

How should I compare two similar listings?

Save both seller links and note the matching sizes, measurements and variants. Compare the cost of the same variant in the same currency, including domestic shipping. Keep the date of the comparison so you can recheck prices later.
